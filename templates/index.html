Project Objective

The objective of this project is to detect shadows present in outdoor images and reduce their effect while preserving important objects, edges and image details.

Input

Outdoor image containing shadows.

Processing

Color conversion, shadow detection, filtering, morphological processing and brightness correction.

Output

Image with reduced shadow effect.

Filters Used

Filter Kernel Size Purpose
Gaussian Filter 5 × 5 Smooths image and reduces noise
Median Filter 5 × 5 Removes impulse noise
Bilateral Filter 9 × 9 Reduces noise while preserving edges

Noise Analysis

Noise can be introduced due to camera sensors, low-light conditions, compression and outdoor environmental conditions.

Kernel Size Effect
3 × 3 Preserves fine details
5 × 5 Balanced smoothing
7 × 7 Stronger smoothing but may remove details

Kernel Size

Kernel size determines the neighborhood of pixels used during filtering and morphological operations.

3 × 3

Less smoothing and better detail preservation.

5 × 5

Recommended balanced kernel size for this project.

7 × 7

More smoothing but possible loss of image details.

Morphological Operations

Opening = Erosion → Dilation

Opening removes small unwanted regions from the shadow mask.

Closing = Dilation → Erosion

Closing fills small holes and connects nearby regions.

Mathematical Formulas

Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 × Precision × Recall / (Precision + Recall)
IoU = TP / (TP + FP + FN)
MAE = Σ|Original - Output| / N
MSE = Σ(Original - Output)² / N
PSNR = 10 log₁₀(MAX² / MSE)

Algorithm

  1. Read the outdoor input image.
  2. Convert BGR image to HSV color space.
  3. Analyze brightness/value channel.
  4. Detect dark regions as potential shadow regions.
  5. Generate a binary shadow mask.
  6. Apply morphological opening and closing operations.
  7. Apply Gaussian smoothing.
  8. Increase brightness in detected shadow regions.
  9. Generate the shadow-reduced output.
  10. Calculate performance metrics.
